# 已接受的增量规则（v0.1.0）

本文件只保存后续使用中确认、可跨报告复用的规则。基础规范在 `SKILL.md` 和 `references/` 中。未来 GitHub 反馈自动化会在PR中追加经确认的候选规则，审查后合并。

## 2026-10-19：来自行业研报逐句底稿与供给研究的确认规则

1. **细分对象一致**：证明医药硝化中间体需求不能直接引用整个医药中间体市场；下游药物、油墨或造影剂的收入/产量只能作为间接驱动证据，必须补齐中间体映射或收窄论点。
2. **逐句原始底稿**：用户要求“底稿”时直接在对话中按“原句→发布主体/原始直达链接→页码/表号/日期→原始数据→核对结论与限制”交付；没有请求不要用下载文件替代。
3. **官方来源不冒名**：政府官网转载媒体报道不等于政府正式统计；第三方投资者问答聚合页不等于交易所官方原文。只有搜索入口而没有直达证据时，应明确说明并优先找正式公告。
4. **同比和价格可复核**：同比必须有本期及基期的同口径原始值；区分成交价、厂家报价、市场均价、出口单位价值，注意规格、币种、时间和统计编码。
5. **交叉验证必须独立**：同一份公告经多家网站转载算一条证据；不同化学品的学术实验只能验证机制，不可直接套用到H酸等具体品种。
6. **产能分层**：项目备案/环评、在建、试产、验收、稳定有效产能和对外可售量逐一拆开；“试生产”“工程进度99%”不能代表稳定达产。
7. **监管约束不等于出清事实**：区分正式文件与征求意见稿、限制工艺与禁产、整改停产与永久退出；历史退出不能移作新一轮成果。缺全国台账时不能宣称净供给已大幅收缩。
8. **全流程效果不可单环节归因**：连续硝化的降本、减排和纯度改善应区分反应器、萃取、废酸循环和还原等工艺贡献；供应商披露或专利实验结果不等于长期工业化效果。
9. **上下文章节不重复**：前节已讲政策，下一节应转向实际改造/复产/项目达产节奏；每段只证明一个明确命题，结论要匹配证据强度。
10. **图表直接验论点**：优先使用实际产销量、项目状态、工艺同口径对比的原始图表；不能用范围过大的全行业市场图替代专用品种需求证据。

详细样例与质控流程见 `references/19-sector-report-evidence-lessons.md`。本轮实际犯错的12项案例与回归检查见 `references/20-session-failures-and-fixes.md`。以后写作应执行句子、对象、状态、反例四道门禁，避免同类错误再次出现。

## 防复发执行规则（2026-10-19）

- **先核实再宣称**：原始页未实际核对，就不能把搜索线索标为“数据准确/已核实”。
- **一次纠错，全链检查**：发现价格区间、同比或产能状态冲突，需同步检查同段相关结论，而不是只改被指出的一句话。
- **失败要阻断**：触发链接伪官方、证据跨范围、同源伪交叉、产能状态混淆、时间错配等错误，先收窄/撤回结论再交付。
- **按用例回归**：每次相关研究写作执行 `references/20-error-library-and-preflight.md` 的典型用例核查；不能只把错误登记在文档中而不执行。

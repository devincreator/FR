# 20. 本轮研报协作失误复盘与防复发检查表

> 日期：2026-10-19。内容依据本轮对话中出现过的写作偏差、反复纠正的需求和前后矛盾的论述。**这是方法论纠错，不是对每一条历史公开数据的重新核实。** 没有重新核实的价格、产能和统计数，不得把它们当作已经得到最终确认的事实。
>
> 适用：研报改写、逐句底稿、寻找官方来源、交叉验证、细分市场空间、政策出清、技术论证、企业项目跟踪。

## 一、错误分类与硬性修正规则

| ID | 对话中出现的问题 | 错误机制 | 以后必须执行的动作 | 禁止直接交付的表现 |
|---|---|---|---|---|

## 二、分级处理：哪些情况必须阻断交付

**P0：事实与证据硬性阻断**（不发布确定性结论）
- 无法定位原文，但声称“已核实”。
- 官方来源身份错误或链接指向搜索入口而非要求的原始证据。
- 数据前后冲突、同比缺基期、价格/产能/产品名/政策生效状态混淆。
- 设计产能冒充实际产量、政策拟实施冒充已生效、历史退出冒充本轮退出。
- 用广义下游数据直接推出细分中间体市场增速，或把单个企业等同全行业。

**P1：论证硬性退修**（先收窄结论再交付）
- 证据只能证明用途/原理，却断言市场规模、行业产能净收缩或盈利改善。
- 多来源实际上为同源转述。
- 忽略反例（如价格区间外样本、销量下滑、装置仍在试生产）。
- 把技术专利的全流程效果单独归功于连续硝化。

**P2：表达与体验缺陷**（发出前修改）
- 一段解决多个问题、重复上节政策。
- 用户要求简短，却附冗余小结与解释。
- 用户要直接底稿，却默认交付文件。
- 图表数据口径与段落所证明的问题不一致。

## 三、防复发协议：五步强制门禁

### 第0步：对齐用户当轮范围
先写内控记录：**对象、论断、所需证据层级、篇幅、交付形式**。如果用户说“行业而非公司”“硝化中间体而非医药中间体”，不得再次换口径。

### 第1步：先建逐句主张和证据映射
将段落每句话拆成事实、测算、研究判断。每项事实要有可打开的**原始链接 + 精确位置 + 时间/单位/地区/范围**。用户要求逐句底稿时，必须一条句子对应一个条目；不能靠段尾一串引用模糊支撑整段。

### 第2步：核原值而非核观点
所有百分比重算本期和基期；检查内部算术及日期；把异常样本、反例单列。若发现同口径矛盾，不得借一句“整体平稳”绕过数据冲突。

### 第3步：证据分层与反例搜索
问：**这条证据“最多”支持到哪一级？** 从“存在用途”到“增长”，从“规划”到“达产”，从“局部工艺改善”到“全行业盈利提升”，任何跨层需要补额外证据。反例没有解决，结论收窄。

### 第4步：交付前六问
1. 每一条事实是否都在链接正文实际出现？
2. 是否把第三方转述、平台入口或搜索摘要说成官方原始来源？
3. 是否把同源重复材料误当独立交叉验证？
4. 是否把年份、价格、同比、产能状态、产品、地域口径混用？
5. 是否证明了标题所说的**细分对象**，而非更大市场或某家公司？
6. 是否服从用户指定的篇幅和交付方式？

任何关键项答“不确定”时，改写为“未核实/仅为推论”，或继续查证，不能宣称完成核实。

## 四、对今后回答的实际约束

- **用户要改写一段**：先交付精简正文；来源未要求时不追加冗长底稿。
- **用户要每句话底稿**：按原句顺序列出原始链接、准确位置、证据、核对状态；数据薄弱处直接说明。
- **用户要官方来源**：优先发行人/政府/交易所原始文件。没有直达证据时明确查不到，不拿媒体转载冒充。
- **用户要市场空间增长或稳定**：优先找该细分品种多期产销量或终端消耗，不能拿宽口径市场填补。
- **用户要供给出清**：先数实际关闭、停产、改造复产、试产、新建达产和外销比例，再讨论未来净供给；不能只重述政策。
- **用户要技术交叉验证**：至少一组原始实验或工业运行数据 + 一组不同机制的独立资料，并清楚声明异品种迁移边界。

## 六、纠错更新方式

当用户指出错误：
1. 当轮明确承认具体错误并更正，不用“基本准确”掩盖。
2. 检查同一段或同一数据链其他地方是否受影响，给出最小影响范围。
3. 记录可复用的触发条件、核查动作和回归测试，不保存对话全文。
4. 先修证据和逻辑，再改文风。
5. 任何“已验证”都需实际打开来源并核对原值；本规则自身**不保证自动核验外部网页**，只能要求执行人员/助手在研究任务中完成这一步。

**最终硬标准：证据没有直接支持的结论，不论措辞多流畅，都不得作为已核实事实交付。**

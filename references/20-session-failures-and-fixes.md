# 20. 本轮研报研究中的实际错误复盘与回归检查

> 复盘日期：2026-10-19。记录的是本次硝化产业链写作对话中**确实出现过的错误、交付偏差或证据链缺陷**。不是对具体公司事实或历史报价的重新审计。对话内部尚未完成一手复核的历史价格、日期和项目进度，统一标注“待重核”，不得从本文件反向引用为权威数据。本文件不包含私聊全文或原始附件。

## 一、总体诊断

最大错误机制是 **先写出有方向性的结论，再为它找看似相关的数字**。当原始证据只能证明相邻问题时，曾发生推论跨级、价格口径混用、产能状态混用、对来源权威性表述过满等问题。

正确工作顺序：**先明确本段的最小可证实命题 → 确认直接证据及反例 → 统一统计口径 → 写出不越界的中心句 → 逐句附一手底稿 → 复核整节与前文的增量价值。**

## 二、逐项记录：错误表现、风险及修复

### E01. 用上位市场的数据代替细分产品需求【已在对话中多次被纠正】
- **具体表现**：用户要求医药硝化反应中间体市场，我曾转而给出整个医药中间体市场规模，以及原料药和中间体合并的出口额；也曾用造影剂业务收入、创新药NDA件数代替硝化中间体销量。用户多次要求回到硝化中间体本身。
- **为何是错误**：统计集合不一致；医药制造活动增长，并不能证明特定硝化中间体消耗增加。
- **影响**：高估细分市场景气和空间，导致报告标题与证据不匹配。
- **修复**：每段加“研究对象”字段；只有同品种产销、真实采购、特定中间体消耗量等才能直接作为规模依据。下游药品或更广行业数据只能标“需求驱动的间接证据”。

### E02. 反例已出现，仍倾向维持“需求稳定”【对话自我纠正】
- **具体表现**：曾用宏源药业某年甲硝唑原料药销量及“年内价格总体平稳”论证需求基础稳定，后来同一研究中补出了销量同比下降约9.81%的反例。
- **为何是错误**：绝对销量较大≠同比稳定；全年内部价格平稳≠跨年需求平稳；单家公司也不代表全行业。
- **修复**：若标题含“稳定/增长”，必须有同口径至少两个期间的数值与反例检查；反例存在时改写为“有一定需求基础”，并显式交代降幅。上述公司同比数字在其他项目中使用前仍须核对正式年报。

### E03. 未先呈现基期就给同比结论【证据展示错误，不等于算术已错】
- **具体表现**：WITS关于中国硝酸纤维素2025年出口量/金额的同比增速先出现在正文中，用户随后质疑“怎么写出来的”。首次交付未同步展示2024年原始记录、分母与计算。
- **为何是错误**：2025年截图只验证2025年数值，不能单独验证2025年同比；读者也无法判断HS 391220的具体覆盖范围。
- **修复**：任何同比至少列“上期/本期/计算式/原始数据库筛选条件”；出口单位价值必须注明不是固定规格的成交价。全球贸易总量要防止欧盟汇总与成员国重复计数。

### E04. H酸价格数据范围与报价口径前后不一致【对话内明确发现冲突】
- **具体表现**：曾写“2025年H酸基本3.6万—4.3万元/吨”，之后又提供了2025年6月约4.4万元/吨的行情点；2026年9月将不同机构市场均价、企业挂牌价与成交区间混在同段。
- **为何是错误**：若已有范围外观测值，就不能继续无条件写全年区间；挂牌价不能直接充当市场成交均价。
- **修复**：建立行情台账：日期、产品纯度/形态、地区、含税、报价类型、样本机构、原始URL；范围声明需全期数据覆盖；冲突先解释口径，不盲目平均。这里的具体历史数值只作错误机制例子，尚需重新从原始行情数据库复核。

### E05. 第三方转载、平台入口与官方原文混称【用户明确纠正】
- **具体表现**：用户索要锦鸡股份“深交所互动易官方来源”，先给出了第三方聚合页，后来又给交易所平台首页而不是该条问答直达页，最后才改为优先正式年报。
- **为何是错误**：来源主体与证据位置不一致；官网首页不能证明具体问答或数字。
- **修复**：严格四分：政府正式文件、政府转载新闻、交易所正式公告、交易所互动平台问答。用户索要“官方来源”时提供对应正式文件/精确URL，无法取得应明示，并换更可靠的一手披露。

### E06. 把规划/环评/试生产误读为有效供给【已纠正口径】
- **具体表现**：讨论广康生化、锦鸡股份、浙江龙盛、善水科技等项目时，早期叙事倾向把设计产能当供给增量；后续才补充试产、验收、已建、在建、自用等状态。尤其“6.6万吨氯代吡啶”整体设计规模中已经包含部分建成产线。
- **为何是错误**：环评审批、设备建设、试产同意、稳定商业运行、对外商品销量不是同一指标。
- **修复**：强制项目状态字段：环评批复→已建→试产→验收→稳定负荷→可售量；按事件日期更新，而不是用最新公告覆盖历史状态。

### E07. 将监管趋严直接推成全国净供给收缩【用户要求转为实际出清】
- **具体表现**：在3.3段落重复2024年政策与2026年征求意见稿，却没有给出全国硝化企业2024年以来的永久退出产能、整改复产量和新项目产量；一度使用2020年42家关闭退出、70家停产整顿作为“目前出清”的主要量化证据。
- **为何是错误**：历史退出不等于本轮退出；整改停产不等于永久关闭；企业数也不能直接换算吨产能；“2026年征求意见稿”不能当正式生效政策。
- **修复**：时间分层：历史整治、当前政策、当前执行、当前产能和未来项目分别统计。缺全国净产能台账时只允许“有效供给释放受约束”，不写全国净减产确定结论。

### E08. 地方样本的分母和改造状态不一致【后续发现】
- **具体表现**：将浙江某地区19家已完成改造与山东41家收到整改提示的企业直接并置，容易给人“山东41家均未完成改造”的印象。
- **为何是错误**：A是已完成改造数，B可能是整体监管对象数；两者统计口径、地区与日期不同。
- **修复**：地方执行台账逐条标明“企业总数/待整改数/已完成数/受检查数/覆盖率”，没有同口径就不计算跨地区改造率。

### E09. 把完整H酸流程的收益归给连续硝化【反复修正】
- **具体表现**：引用H酸连续硝化、萃取、加氢还原组合专利中的综合收率、硫酸节省、减少铁泥与废水效果，初期表述容易让读者误解为“只改硝化反应器”即可实现全部收益。
- **为何是错误**：萃取、酸回收、还原、碱熔和废水后处理共同决定全厂经济性和环保指标。
- **修复**：所有工艺效果加“归属工序”一列；引用专利时标注“技术申请人披露的方案/实施例效果”，不得当作独立第三方或工业长期运行实绩。其他底物微反应器实验只能支持机制，不能套用H酸改善百分比。

### E10. 将供应商案例误当多方实证【证据独立性缺陷】
- **具体表现**：连续硝化项目中的硝酸节省、杂质改善、示范装置数量多来自供应商或研发团队披露；不同媒体重复报道同一项目时，早期容易形成“多来源交叉验证”错觉。
- **为何是错误**：不同网站 ≠ 不同原始数据来源；工业设备商技术效果缺少相同工况下第三方验证。
- **修复**：统计真正独立来源数，至少区分科研论文、业主公告、政府验收、供应商资料；按“实验室 / 中试 / 工业试产 / 稳定连续生产”标注成熟度；没有独立验证就保留“据供应商披露”。

### E11. 配图与论点没有严格对应【用户推动纠偏】
- **具体表现**：在要求“当前医药硝化中间体稳定或增长”时，曾推荐较久以前的甲硝唑原料药市场图和更宽泛的碘造影剂规模图；它们分别说明历史需求及下游市场，而非直接量化当前硝化中间体市场。
- **修复**：图标题标明证据层级；优先“目标中间体需求量、产能与利用率、下游消耗量、同产品工艺对比”；历史图只证明历史，不暗示2026年需求。

### E12. 回答的颗粒度与需求多次不一致【交付错误】
- **具体表现**：用户要求“重写一段”“短一点不要废话”时，曾给长篇展开；用户要逐句底稿时，曾先制作Word/PDF，随后用户明确要求直接在对话中呈现；前文讲政策之后，新段落继续复述政策。
- **修复**：按本轮具体交付：短段落先给可复制正文；需要底稿则逐句给原句、出处、数据位置、核对状态；用户要官方链接只答官方链接和对应位置；前后段不能重复同一证据层级。

## 三、哪些属于确定错误，哪些属于尚待复核

- **确定可归责的问题**：研究范围偏移、不能从单年数据推出同比、报价类别混用、第三方来源冒充官方直达、产能状态混淆、监管事实当净出清、不同工艺效果归因混乱、篇幅与交付方式不符。
- **对话中发现的数值/结论冲突**：2025年H酸价格范围与后来列出的行情点不一致；单个甲硝唑企业2025年销量下降与“稳定需求”论断不完全相符。当前文件只确认“对话内部存在冲突”，不独立裁定所有行情原始值真伪。
- **待补证而非必然错误**：具体企业试生产最新进度、硝化全国净出清幅度、连续硝化节酸的工业长期效果、各品种当前价格和有效供给；不得因为有疑点就自行宣称其反面成立。

## 四、四道强制回归门禁

**G1. 句子门禁**：每句事实是否有可打开的原文直接链接与精确段落、时间及原始值？如无，降级成推论或删去。

**G2. 对象门禁**：市场是否同品种、同地域、同统计口径？若证据是更广市场或更下游行业，只能讲潜在传导，不能写已证实增长。

**G3. 状态门禁**：对产能、政策、项目、实验效果、价格分别问“已发生还是计划”“官方还是转载”“报价还是成交”“哪道工序贡献”。任何混淆就改写。

**G4. 反例门禁**：写“稳定/增长/出清/优势”前必须检索相反证据：销量下降、另一行情报价、停产可复产、扩产或试产、新技术对经济性的不利因素。若反例不能解释，收窄结论。

## 五、默认纠错流程

当用户指出“这个来源不行”“这不是硝化中间体市场”“不要重复政策”“每句话给出处”时：
1. 先识别**哪一个承诺没有做到**（主题、可信度、原始出处、口径还是交付）。
2. 不机械追加更多相邻数据；替换为能直接回答同一研究对象的新证据。
3. 如不能补齐一手数据，明确“未找到/无法核实”，给较窄但可证实的版本。
4. 对旧内容的更正，要注明此前错误是什么，不只是输出一个不同的新版本。
5. 不将当次的具体价格、事故或产能数值写成跨报告永久规则。

**总教训**：质控并非把句子后面添一个链接，而是核对“该链接上的事实究竟能证明这句话的哪一部分”。

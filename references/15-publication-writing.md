# 15. 面向公开阅读的研报写作与编辑规范

## 首页是一张决策地图

读者不打开正文也应看懂：**结论是什么、为什么现在、关键三条证据、盈利受什么影响、市场预期差是什么、风险在哪里**。摘要不是正文段落机械剪贴；所有数字仍需标记年份、单位与出处。

建议首页顺序：一句话投资观点 → 催化/变化 → 三条经验证的论据 → 核心预测与估值假设 → 风险提示。未获得机构批准时不得随意填写评级和目标价；评级术语使用发布机构定义。

## 标题层级

全文题目回答投资判断；章标题解释上一级观点；小节标题再给子原因。一组标题连着读应成为通顺的逻辑论证，而不是“1 行业概况、2 公司介绍、3 市场分析”。标题要有边界，不应把未经验证的猜想写成确定事实。

## 每段的四句检查

1. **判断**：第一句指出因果关系，避免抽象口号。
2. **机制**：读者为什么应该相信，有哪些关键条件。
3. **证据**：用一个至两个决定性数据、比较或原始事实支持；注明来源。
4. **意义**：这些证据如何改变需求、利润或风险判断。

每段以一个子论点为中心，不为了凑字数而挤进过多信息。数字重要时可先放表，正文只解释读者该看到什么。

## 读者认知负担最小化

- 术语初见先解释作用，随后统一简称，不能反复切换中文/英文别名。
- 让比较具备参照：比什么年份、同谁对比、变化多少、为什么重要。
- 少用套话（持续赋能、稳步推进、景气可期、打造壁垒）；用可量化事实替代。
- 主动语态，避免连续长定语；不用破折号制造情绪；少加引号强调普通名词。
- 尽量让一张图回答一个问题；颜色之外还要靠图例、标签和直接标注传达差异。
- 字数不是目标；信息密度来自删去不支持结论的背景和重复。

## 数字书写

同一张表统一单位、保留精度、预测 E 和实际 A；区分同比、环比和百分点；金额不要省略币种；百分比不是百分点；精度不得超过来源真实精度。原药吨和有效成分吨必须写换算。

## 常见错误的改写

**空标题**：`行业发展空间广阔` → `下游 XX 应用量增长，预计推动 YY 品类需求增加（需数据验证）`。

**空段落**：`公司市场竞争力突出，未来发展可期` → `公司某产品成本或渠道优势可以从单位成本、订单与份额变化检验；资料尚不足时不得推断优势已经兑现`。

**结论跳跃**：`新产能投产带来利润` → `试产→稳定负荷→合格品→客户认证→出货→确认收入→扣除折旧及运营成本`。

## 两层编辑

**结构编辑**：先检查标题树是否因果闭合、是否遗漏主要反论点、是否重复章节；再检查数据布局。

**语言编辑**：再改句式、消歧义、统一术语和可读性，最后核对数字、引用链接、脚注有没有在润色过程中发生变化。

## 表述不确定性的正确方式

事实用“根据××披露，截至××”；测算用“按××假设测算”；预测用“预计/情景假设”；没有证据不要装作确定。每条争议结论注明敏感参数和反例。不能靠“或许”“有望”替代必要的分析。

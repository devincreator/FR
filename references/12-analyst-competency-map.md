# 12. 证券研究员能力地图（全部事项索引）

本清单不是要求每篇报告都写全部内容，而是判断研究者在必要场景下是否有能力完成。勾选前必须用一个真实案例或可复算表格证明掌握。

## A. 研究能力
- [ ] 能把表面问题还原为投资者关心的决策问题，写出可证伪的核心假说。
- [ ] 能拆出相互支撑而不重叠的论点树，区分主要矛盾和次要信息。
- [ ] 能区分经济增量、渠道补库、价格周期、会计确认和估值重估。
- [ ] 能找到反对自己结论的证据，明确何时放弃研究假说。

## B. 行业需求
- [ ] 识别终端用户、使用场景、预算和替代方案。
- [ ] 明确 TAM、SAM、可实现销量与收入不是同一口径。
- [ ] 用两条独立路径计算需求量，注明单位、时间与地理范围。
- [ ] 区分一次性采购、存量替换、渗透率增长、实际终端消耗。
- [ ] 建立增长驱动和需求弹性，辨别经济周期与结构性因素。

## C. 供给与竞争
- [ ] 分清设计/合规/有效/试产/商业运营产能、产量、库存和外销量。
- [ ] 对同用途竞品分析产品力与经济性，而不是只列竞争厂家。
- [ ] 理解产能集中度、成本曲线、工艺约束、认证和渠道壁垒。
- [ ] 对公司扩产、竞争对手扩产、退出及成本变化进行情景分析。
- [ ] 理解产业链绝对上下游与某环节的相对上下游。

## D. 公司经营
- [ ] 读懂招股书、年报、问询回复、临时公告、环评、专利和登记文件。
- [ ] 能拆公司业务结构、客户与区域、研发工艺、股权和治理。
- [ ] 能构造存量现金流与新增项目的独立盈利模型。
- [ ] 能核查资本开支、建设、试产、爬坡、认证、交付和营收确认时差。
- [ ] 能判断份额获得的充分条件与可观测指标。

## E. 财务与模型
- [ ] 理解利润表、现金流量表、资产负债表的连接与科目附注。
- [ ] 做产品/分部量价成本模型，检查产销、毛利与营收勾稽。
- [ ] 读懂折旧、在建转固、存货、应收应付、票据及周转天数。
- [ ] 能识别经营增长与会计政策/列报变化的区别。
- [ ] 能用利润率分解、杜邦分解、ROIC和自由现金流评价质量。
- [ ] 能处理税率、汇率、借款、少数股东权益、股本等关键变量。
- [ ] 有底部/中性/高景气三套独立经营假设，而非利润倒填。

## F. 估值与投资
- [ ] 理解PE、PB、EV/EBITDA、DCF、分部估值适用条件。
- [ ] 构建可比公司组，并说明业务、资本密度和周期可比性。
- [ ] 能识别市场价格隐含的增长率/盈利/估值预期。
- [ ] 能完成敏感性、逆向估值及关键风险量化。
- [ ] 能区分催化剂与长期利好，并制定动态跟踪指标。

## G. 来源核查与合规
- [ ] 追溯一级披露并记录页码、时间、单位、原始文件。
- [ ] 检验数据是否真正独立交叉验证，不循环引用同一二手来源。
- [ ] 区分事实/测算/假设/观点，准确声明预测不确定性。
- [ ] 对政策、事故、监管、许可等敏感事实独立查证。
- [ ] 可审计每张图表数据的计算公式、版权与出处。

## H. 表达与交付
- [ ] 首页摘要和目录可独立传达论点链。
- [ ] 标题为结论性因果句，单段只写一项判断。
- [ ] 图表负责解释变量关系，不替代正文逻辑。
- [ ] 能按用户要求忠实整理纪要、点评、深度、PPT而不过度发挥。
- [ ] 交付物可修改、可复算、可回溯，保留版本及变更日志。
- [ ] 任务结束复盘，沉淀抽象可执行规则；不擅自上传私密数据。

## 建议学习顺序
先练一次「产品需求量三法估算与查源」，再练「公司产品量价成本分解」，然后练「三表联动+情景估值」，最后练「首页标题摘要和反例审查」。每次训练留可审计案例，质量优先于速度。
